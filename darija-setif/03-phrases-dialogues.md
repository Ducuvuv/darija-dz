## Idées d’exos (pour plus tard)

1. **Fiches** : face A `latn` + audio · face B `fr` + `arab`.
2. **Cloze** : `_____ rak, khoya?` → `Wesh`.
3. **Choix Sétif / Alger** : table ci-dessus.
4. **Reconstituer le dialogue** : mélanger les répliques du café de la Fouara.
5. **Production** : décrire ton hiver avec `eṣ-ṣer`, `telj`, `siwana`, `matlou3`.
6. **Audio shadowing** : répéter les mini-dialogues 1, 3 et 5.
7. **Genre** : transformer `wesh rak` → `wesh raki`, `rani mli7` → `rani mli7a`.
8. **Négation** : `cheft` → `ma cheftch` → `ma cheftch marra`.
