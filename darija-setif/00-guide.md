# Guide du parler sétifien

Corpus pédagogique de **darija algérienne**, axé sur **Sétif** (Hauts-Plateaux de l’Est). Pas d’orthographe officielle : la transcription ci-dessous est celle des SMS / réseaux, pour que tu puisses plus tard générer des fiches, quiz et audios.

---

## Comment lire une entrée

Chaque mot du lexique a les mêmes champs :

| Champ | Rôle |
| --- | --- |
| `id` | Identifiant stable (pour Anki, apps, scripts) |
| `latn` | Transcription latine (alphabet « chat ») |
| `arab` | Graphie arabe approximative |
| `fr` | Sens en français |
| `ex` | Mini-phrase sétifienne + traduction |
| `region` | `setif` = très local · `est` = Est algérien · `dz` = courant partout |
| `niv` | A1 / A2 / B1 (pour doser les exos) |
| `tags` | Thèmes (salutations, nourriture, froid, famille…) |

**Priorité d’apprentissage :** d’abord `region: setif` + `niv: A1`, ensuite le socle `dz`.

## Alphabet « chat » (à coller partout)

| Signe | Son | Arabe | Exemple |
| --- | --- | --- | --- |
| **3** | gorge, « ‘a » | ع | `3andek` عندك |
| **7** | h fort | ح | `7it` حيط |
| **9** | qaf (clic du fond de gorge) | ق | `9ahwa` قهوة |
| **kh** | comme jota espagnole | خ | `khobz` خبز |
| **gh** | r grasseyé / r parisien | غ | `ghraif` غرايف |
| **ch** | ch de *chat* | ش | `chikh` شيخ |
| **dj** | dj de *Djamel* | ج | `djedj` جاج |
| **g** | g de *gare* (qaf local [g]) | ق/گ | `denq` / `deng` دنق |
| **u** | ou | و | `souq` سوق |
| **i** | i | ي | `mli7` مليح |
| **e** | e muet / schwa | — | `kteb` كتب |

À Sétif, le **qaf** se réalise souvent **[q]** (plus « classique » qu’à Alger où c’est un coup de glotte). Mais beaucoup de mots locaux se disent avec **[g]** : `denq`, `tarbeg`, `gta3a`. On transcrit comme on entend.

## Ce qui fait « Sétif » (à connaître avant le reste)

Le parler sétifien est un **arabe hilalien de l’Est** (groupe Sétif–Batna), avec un fond amazigh (chaoui / kabyle des montagnes proches) et un français très présent. Ce n’est pas un autre dialecte que la darija nationale : c’est **le même système**, avec des mots, des réflexes et une musique propres.

### 1. *lah* = pourquoi

Ailleurs on dit surtout `3lach` / `3lah`. À Sétif, **`lah`** est un tic de langue, souvent allongé : *hada laaah ?*

| Sétif | Ailleurs | Sens |
| --- | --- | --- |
| `lah` | `3lach` | pourquoi |
| `hada lah hada` | `3lach hakka` | pourquoi comme ça ? (étonnement) |

### 2. *marra* dans la négation

Ailleurs on intensifie avec `ga3` (« du tout »). À Sétif :

> `ma djitch marra` = je ne suis **jamais** venu / je ne suis **pas du tout** venu  
> (ailleurs : `ma djitch ga3`)

### 3. *el-lout / el-louta* = en bas

> `hbet el-lout, rah Ahmed el-louta`  
> descends en bas, Ahmed est en bas

Ailleurs : `ta7t` / `lte7t`.

### 4. *dok / drok* = maintenant

Est algérien : `drok`, `dok`. Ouest : `dork`. Centre : `dorka`.

### 5. *nchti* = j’aime

De *nchtehi* (je désire). Très Est / Hauts-Plateaux.

> `nchti Sṭif bezzaf` = j’aime trop Sétif  
> (ailleurs souvent `n7ebb`)

Pour **vouloir faire** : beaucoup de Sétifiens disent `7aba ndir` plutôt que `7abbit ndir`.

### 6. *yasir* à côté de *bezzef*

Les deux veulent dire « beaucoup ». `yasir` est bien implanté dans certains villages / familles sétifiennes (ex. El Hachama).

### 7. Famille : le code *3ajouz / chikh*

Marqueur très sétifien (et des Hauts-Plateaux) :

| On dit | Ça désigne |
| --- | --- |
| `el-3ajouz ta3na` | **ma / notre mère** |
| `el-3ajouz ta3kom` | votre mère |
| `ech-chikh ta3na` | **mon / notre père** |
| `ech-chikh ta3kom` | votre père |
| `eṭ-ṭfel ta3na` | mon / notre frère |
| `eṭ-ṭefla ta3na` | ma / notre sœur |
| `nana` / `jedda` | grand-mère |

Ce n’est pas méchant : c’est le parler de la maison.

### 8. *shiakha* = la causette

S’asseoir, parler, rire, passer le temps. Verbe : `nchaykhou`.

> `nlouhou fouam shaykha m3ahom` = on jette une petite causette avec eux (et on s’en va)

### 9. *denq* = regarder

> `denq!` = regarde ! (ailleurs `chouf` / `3ayen`)

### 10. Table et climat

Sétif = **froid**, **neige**, **grillades**, **pâte**. Trois mots à graver :

- `berboucha` = couscous (pas `seksou` / `t3am`)
- `ghraif` = crêpes mille-trous (baghrir)
- `matlou3` = pain levé cuit sur plaque

Et pour l’hiver : `eṣ-ṣer`, `el-jlida`, `es-smiqri` (froid qui mord).

## Mini-grammaire (pour les exos)

### Le « je suis / tu es » : *rani, rak…*

| FR | Darija |
| --- | --- |
| je suis | `rani` |
| tu es (H) | `rak` |
| tu es (F) | `raki` |
| il est | `rah` / `rahu` |
| elle est | `rahi` / `raha` |
| nous sommes | `rana` |
| vous êtes | `rakom` |
| ils/elles sont | `rahom` |

> `rani hna` = je suis là  
> `wesh rak?` = comment tu vas ? (H)

### Pronoms

| FR | Darija |
| --- | --- |
| je | `ana` |
| tu (H) | `nta` |
| tu (F) | `nti` |
| il | `huwa` |
| elle | `hiya` |
| nous | `7na` |
| vous | `ntuma` |
| ils/elles | `huma` |

### Possession : *ta3*

`ta3i` à moi · `ta3ek` à toi · `ta3u` à lui · `ta3ha` à elle · `ta3na` à nous · `ta3kom` à vous · `ta3hom` à eux

> `ed-dar ta3na` = notre maison

### Négation : *ma … ch*

On entoure le verbe : `ma + verbe + ch`

> `ktebt` → `ma ktebtch` (je n’ai pas écrit)  
> `rani mli7` → `ma ranish mli7` (je ne vais pas bien)

À Sétif, on peut coller **`marra`** pour appuyer : `ma cheftuch marra`.

### Conjugaison type : *kteb* (écrire)

| | Passé | Présent |
| --- | --- | --- |
| je | `ktebt` | `nekteb` |
| tu (H) | `ktebt` | `tekteb` |
| tu (F) | `ktebti` | `tekketbi` |
| il | `kteb` | `yekteb` |
| elle | `ketbet` | `tekteb` |
| nous | `ktebna` | `nekketbu` |
| vous | `ktebtu` | `tekketbu` |
| ils | `ketbu` | `yekketbu` |

Futur courant : `raye7 + verbe` ou simplement le présent.  
Progressif : `rani nekteb` = je suis en train d’écrire.

### Genre

Masculin = souvent consonne finale. Féminin = souvent **-a**.  
`mli7` / `mli7a` · `kbir` / `kbira` · `sghir` / `sghira`

## Français dans la phrase

Normal à Sétif (comme partout en Algérie) : on greffe le français dans la darija.

> `rani nro7 lel lycée`  
> `3andek le wifi?`  
> `stiki ech-choumbera` = range / nettoie la chambre (`astiquer` + `chambre`)

Ne cherche pas à « purifier » : c’est le vrai parler.

---

## Prononciation sétifienne (oreille)

- Musique plus **« sèche »** et consonantique que l’oranais.
- **qaf** souvent gardé (`9al`, `9ahwa`).
- **Pluie** : `en-nou` (ailleurs `ech-chta` / `el-mṭar`).
- **Œufs** (Est) : `la3dham` (Alger : `wled el-djedj`).
- **Couscous** : `berboucha`.
- Allongements expressifs : *laaah*, *bezzaaaf*, *yaaaasir*.

## Niveaux pour tes futurs exos

| Niveau | Contenu |
| --- | --- |
| **A1** | salutations, `rani/rak`, `lah`, `wesh rak`, chiffres 1–10, nourriture de base, `nchti`, `dok` |
| **A2** | famille sétifienne, marché, froid, verbes du quotidien, `shiakha`, `denq`, `marra` |
| **B1** | rural, argot, météo fine, marchandage, récits, code-switching |

Les tags `setif` dans le lexique = **priorité Sétif**. Les tags `dz` = socle pour comprendre le reste du pays (télé, rap, famille à Alger, etc.).
