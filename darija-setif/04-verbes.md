# Verbes modèles (pour fiches de conjugaison)

Même schéma partout. Colle ça dans des tableaux « je / tu / il… » plus tard.

Légende : **H** = homme, **F** = femme. Le passé est le plus utile à l’oral sétifien ; le présent se fait avec `rani / rak` + verbe.

---

## 1. Être / se trouver — `rani`

Pas un verbe classique : c’est **ra-** + pronom.

| FR | Darija | Ex |
| --- | --- | --- |
| je suis | rani | rani hna |
| tu es (H) | rak | rak mli7? |
| tu es (F) | raki | raki 3eyyana? |
| il est | rah / rahu | rah fel-souq |
| elle est | rahi | rahi ta9ra |
| nous sommes | rana | rana jayin |
| vous êtes | rakom | rakom 7aderin? |
| ils/elles sont | rahom | rahom ychaykhou |

Négation : `ma ranish`, `ma rakch`, `ma rakich`, `ma rahch`, `ma rahich`, `ma ranach`, `ma rakomch`, `ma rahomch`.

---

## 2. Aller — `rah` (il est parti) / `nro7` (je vais)

Racine **r-w-7**.

| | Passé | Présent |
| --- | --- | --- |
| je | ro7t | nro7 |
| tu (H) | ro7t | tro7 |
| tu (F) | ro7ti | tro7i |
| il | rah | yro7 |
| elle | ra7et | tro7 |
| nous | ro7na | nro7ou |
| vous | ro7tou | tro7ou |
| ils | ra7ou | yro7ou |

> ghodwa nro7 lel-jami3a — demain je vais à la fac  
> el-bare7 ro7t l 3in el-Fouwara — hier je suis allé à la Fouara

Impératif : `rou7` (H) · `rou7i` (F) · `rou7ou` (vous).

## 6. Aimer / vouloir — `nchti` (Sétif) et `nbghi`

À Sétif, **aimer** = souvent `nchti`. **Vouloir** = `nbghi` ou `7aba`.

### nchti (présent, le plus courant)

| FR | Darija |
| --- | --- |
| j’aime | nchti |
| tu aimes (H) | tchti |
| tu aimes (F) | tchti |
| il aime | ychti |
| elle aime | tchti |
| nous aimons | nchtiou |
| vous aimez | tchtiou |
| ils aiment | ychtiou |

> nchti Sṭif yasir — j’aime trop Sétif  
> nchtiha — je l’aime (elle)

### 7aba (je veux faire)

> 7aba nro7 — je veux y aller (H : `7abb`)  
> 7aba ndir berboucha — je veux faire du couscous

## 11. Avoir — `3and-`

Pas de verbe « avoir » : **3and** + pronom.

| FR | Darija |
| --- | --- |
| j’ai | 3andi |
| tu as | 3andek |
| il a | 3andu |
| elle a | 3andha |
| nous avons | 3andna |
| vous avez | 3andkom |
| ils ont | 3andhom |

Négation : `ma 3andich`, `ma 3andekch`, `ma 3anduch`…

> 3andi waqt — j’ai le temps  
> ma 3andich drahem — j’ai pas d’argent

## Négation (à coller sur n’importe quel verbe)

```
ma + VERBE + ch
```

| Affirmatif | Négatif |
| --- | --- |
| kilt | ma kiltch |
| nro7 | ma nro7ch |
| rani mli7 | ma ranish mli7 |
| 3andi | ma 3andich |
| cheft | ma cheftch |
| cheft marra (Sétif, appuyé) | ma cheftch marra |

---

## Futur / intention (oral)

On n’utilise presque jamais un « vrai » futur. Trois options :

1. présent : `nro7 ghodwa` — je vais demain  
2. `raye7 + verbe` : `raye7 nro7` — je vais y aller  
3. `7aba + verbe` : `7aba nro7` — je veux / je vais y aller

Progressif : `rani + présent` → `rani nakol` = je suis en train de manger.
