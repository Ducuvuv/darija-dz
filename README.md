# Darija algérienne — apprendre pour retenir



Corpus de **darija algérienne générale** (comprise à Alger, Constantine, Oran, Sétif…), avec une **couche Sétif** en bonus.



Pas un dictionnaire à lire d'un coup. Des **petits decks**, des **phrases**, des **exos de rappel**.  

Chaque carte : **français** → **arabe voyellisé** + latin + exemple.



---



## Comment étudier (5–10 min)



1. **Cache** la colonne arabe. Lis le français. Dis la darija **à voix haute**.

2. Vérifie : arabe voyellisé + `latn`. Si faux, relis **la phrase**, pas le mot seul.

3. **8 à 12 mots nouveaux** par session. Pas plus.

4. Chaque session : **moitié ancien + moitié nouveau**.

5. Fais les **mini-exos** en fin de deck **sans regarder** le tableau.



**Rythme (répétition espacée) :**



| Jour | Quoi |

| --- | --- |

| J1 | Deck A1 du jour (8–12 cartes) |

| J2 | Même deck + 8 nouvelles |

| J4 | Ancien deck (rappel) |

| J7 | Mix (fichier `05-revisions.md`) |

| ensuite | revoir les ratés, pas tout le lexique |



Face Anki : `fr`  

Dos : `arab` + `latn` + `ex_arab` / `ex_fr`



Sens inverse une fois sur deux (arabe → français) à partir de la 2ᵉ semaine.

## Colonnes des cartes



```

id | fr | arab | latn | ex_arab | ex_fr | niv | tags

```



- `fr` — **face** (ce que tu caches)

- `arab` — **arabe voyellisé** (حَرَكَات) — à mémoriser

- `latn` — alphabet chat (`3` ع, `7` ح, `9` ق)

- `ex_arab` / `ex_fr` — mini-phrase (contexte)

- `niv` — A1 / A2 / B1 / B2

- `tags` — `dz` = partout · `setif` = local · thème

## Arabe voyellisé (lire les ḥarakāt)



| Signe | Nom | Valeur ici |

| --- | --- | --- |

| َ | fatḥa | a court |

| ِ | kasra | i court |

| ُ | ḍamma | u / ou court |

| ْ | sukūn | pas de voyelle (amas : شْحَالْ) |

| ّ | shadda | consonne double (حَبّْ) |



Exemples : **وَاشْ رَاكْ** · **رَانِي مْلِيحْ** · **قَهْوَة** · **شْحَالْ**



Le `latn` sert d'aide si les voyelles te bloquent. L'objectif, c'est de **lire `arab`**.

## Chemin vers le B2



| Composante | Cible B2 | Ce corpus |

| --- | --- | --- |

| Lexique passif | ~2 000 mots | **~1 205 mots** ✓ |

| Idiomes / tournures | ~150–200 | **~180** ✓ |

| Phrases & dialogues | syntaxe naturelle | **~155** ✓ |

| Écoute intensive | vitesse, accents | **à toi** (indispensable) |



Le corpus couvre **quasi tout le lexique B2**. L'écoute (séries, radio, podcasts) te donne la **fluidité** à l'oral.
